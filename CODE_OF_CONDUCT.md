# Code of Conduct

## Our Goal

Lynx Agent is an engineering project, but it should still be a welcoming place
to learn, experiment, and contribute.

We want discussion here to be:

1. respectful
2. technically honest
3. generous with context
4. focused on helping the project improve

## Expected Behavior

Please try to:

1. assume good intent and ask clarifying questions before escalating
2. critique ideas, code, and evidence rather than people
3. be explicit about uncertainty, tradeoffs, and unverified claims
4. keep benchmark, security, and safety discussions grounded in facts
5. help newer contributors get oriented when possible

## Unacceptable Behavior

This project does not allow:

1. harassment or personal attacks
2. discriminatory language
3. intimidation, threats, or sustained hostility
4. posting private credentials, screenshots, traces, or personal data without consent
5. intentionally misleading benchmark claims or hidden benchmark-only patches

## Project-Specific Norms

Because this project is about automation and agent behavior, a few extra norms
matter:

1. do not present app-specific hacks as general capability gains
2. do not hide risky shortcuts behind vague wording
3. do not publish sensitive device traces or user data
4. do not overstate what a benchmark result proves

## Enforcement

The maintainer may edit, remove, or reject comments, issues, or pull requests
that violate these guidelines.

Repeated or severe violations may result in being blocked from further project
participation.

## Reporting

If something here feels off or unsafe, contact the maintainer privately rather
than escalating a public thread.
